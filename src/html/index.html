About the app

Small tasks. Clear deadlines. One place to keep track.

Managing several courses can make a simple to-do list hard to follow. Studyline connects each task to its course, due date, description and notes, so the information needed to start is kept together.

  • Capture the whole task. Record what needs doing, which course it belongs to and when it is due.
  • Keep the plan accurate. Edit any detail when requirements change, or remove a task after confirming the deletion.
  • See what is next. All tasks appear in due-date order, with overdue tasks clearly labelled.
  • Return to your work. Tasks stay in the same browser after refreshing. The demonstration login gates the task interface.

This is a browser-based coursework prototype. Read Ethics & privacy before storing personal information.

The study routine I am adopting

I want a plan that is specific enough to act on and flexible enough to update. This is how I plan to use Studyline:

  1. Plan the week on Sunday. Spend 20 minutes checking assignments, quizzes and deadlines across my courses.
  2. Break large assignments down. Create separate tasks for reading the brief, building, testing and checking the submission.
  3. Choose three priorities each day. Consider both the deadline and the amount of work involved.
  4. Work in focused blocks. Study for about 45 minutes, take a 10-minute break, and spend five minutes updating the plan in the evening.
  5. Leave time to check. Aim to finish a first version two days before the deadline so there is time for testing and revision.

A plan is useful when it is easy to return to.
